Zero-Config Discovery

Works with your local AI coding tools out of the box

No OAuth flows, no API keys, no background proxies. Toki reads your local session histories directly and safely in read-only mode.

Claude Code No Login
~/.claude/projects

Deduplicates streamed content blocks by message & request ID, tracks advisor iterations & 1h cache writes, and reads both .jsonl and .jsonl.zst archives.

Codex No Login
~/.codex/sessions

Accurate cumulative snapshot diffing, baseline rebase recovery, interrupted-turn gap reconciliation, fork suppression, and cross-file deduplication.

Antigravity No Login
~/.gemini/antigravity*

Native C SQLite3 (including closed WAL databases via immutable read) paired with a pure Swift Protobuf wire decoder and dynamic model-name learning.

OpenCode No Login
~/.local/share/opencode

Incremental SQLite3 rowid scanning across v1 and v2 schemas with fork-boundary filtering and legacy JSON history fallback.

Crafted for macOS

Fast, private, and built like a native Apple utility

Every kilobyte and interaction is tuned for staying out of your way while giving instant clarity when you click.

2.8 MB Universal Native

Built 100% in Swift 6, SwiftUI, AppKit, and Swift Charts for Apple Silicon and Intel. No Electron, no bundled Node runtime, tiny memory footprint.

100% Local & Read-Only

Your prompts and code never leave your Mac. Toki never writes to your AI tools' directories; its only optional network request caches public LiteLLM pricing.

Event-Driven Refresh

Incremental byte-offset scan cache + FSEvents directory watching + automatic local midnight rollover + instant wake-from-sleep refresh.

Cost & Cache Savings

See estimated spend and exact prompt-cache savings in USD or CNY, complete with cache hit rate, custom exchange rate, and per-model rate overrides.

Interactive Trend Charts

Switch between Tokens, Cost, and Requests across Today (24h), 7 Days, and 30 Days with daily bar-top totals and floating hover breakdown cards.

Power-User Config & CLI

Customize paths, aliases, filters, and prices via ~/.config/toki/config.json (plus T3 Code compatibility), or pipe live JSON via Toki --dump-json.

Install & customize

Install on macOS 14+

1
Download Universal DMG

Grab the latest release for Apple Silicon & Intel Macs and drag Toki.app into /Applications.

2
First-launch Gatekeeper note

Open-source builds are ad-hoc signed. If macOS blocks the first launch, run once in Terminal:

xattr -dr com.apple.quarantine /Applications/Toki.app
3
Launch & enable Launch at Login

Open Toki from Spotlight, click the menu bar meter, and customize format, currency, and language in Settings.

Optional ~/.config/toki/config.json

Works out of the box with zero config. Add custom source paths, model aliases, filters, or price overrides whenever you need: 

{
  "modelAliases": {
    "my-proxy/claude-sonnet": "claude-sonnet-4-6"
  },
  "priceOverrides": {
    "my-custom-model": {
      "inputCostPerMillionTokens": 3.0,
      "outputCostPerMillionTokens": 15.0
    }
  },
  "sources": {
    "claude": ["~/work/.claude"],
    "codex": ["~/work/.codex"]
  }
}

CLI inspection: /Applications/Toki.app/Contents/MacOS/Toki --dump-json --days 7
